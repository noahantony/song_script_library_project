# ஒரு சிறிய நம்பிக்கை

## காட்சி 1 — காலை

**காட்சி:** ஒரு இளைஞன் ஜன்னல் அருகே அமர்ந்து சிந்திக்கிறான்.

**உரையாடல்:**

இன்று கடினமாக இருக்கலாம். ஆனாலும் நான் முயற்சியை நிறுத்த மாட்டேன்.
